Privacy Policy

Last updated: October 9, 2026

Overview

XANADU Gmail Cleaner is a personal-use application designed to automatically delete messages from the Spam and Trash folders of the owner's Gmail account.

Google User Data

The application accesses Gmail data through the Gmail API solely to identify and delete messages in the Spam and Trash folders.

Data Storage

OAuth credentials are stored locally on the owner's computer. Gmail message contents are not stored in an external database.

Data Sharing

Gmail data is not sold or shared with third parties.

Data Retention

The application does not retain copies of deleted Gmail messages.

Security

Access credentials are kept in a locally protected directory and are not published on this website.

Contact

For questions about this application, please contact the application owner through the support email listed on the Google OAuth consent screen.
